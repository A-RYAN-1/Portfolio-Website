About me

I'm an Associate Software Engineer at Josh Software, where I build production backend systems in Go and Ruby on Rails. My work centers on IoT data pipelines, billing systems, and the APIs and background jobs that keep them reliable at scale.

On the SimplySmart platform, I've traced inconsistent water meter readings back to MQTT ingestion issues, cut data inconsistencies by 90% by moving the pipeline to asynchronous processing, and built background jobs that detect non-responsive and abnormally-consuming meters and report on them automatically via AWS SES. I also debug production billing defects — arrears, penalties, due-date logic — and ship the APIs that let admins fix consumption data without touching the Rails console.

Beyond backend work, I build the React interfaces that sit on top of these systems — admin dashboards, approval workflows, fraud-detection tooling — and handle staging deployments and cloud automation on AWS, so I end up working the full path from database to browser.

I'm most interested in backend engineering, distributed systems, and IoT platforms — how large-scale systems stay reliable under real-world data, and how to design them so they're easy to operate, not just easy to build.

Outside of tech, I enjoy playing basketball and following sports. I believe teamwork, discipline, and continuous learning are essential in software engineering, and I strive to bring that mindset into every project I work on.

I also write about the production bugs I chase — read them on Medium.
