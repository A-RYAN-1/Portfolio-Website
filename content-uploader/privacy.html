Privacy policy

content-uploader. Last updated 2026-11-19.

Who uses it

Only the owner of the YouTube channels it manages. Nobody else signs in to it.

What it accesses

  • Permission to upload videos to the owner's channel.
  • Read access to the owner's channel details.
  • Read access to the owner's channel analytics (views and watch time).

What it stores

The sign-in token is kept in a private file on the owner's computer. Analytics numbers are kept on the same computer to decide which topics to cover next. Nothing is sold, shared or sent to anyone other than Google's own APIs.

Google API data

content-uploader's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time from Google account permissions. The local token file is then deleted.
